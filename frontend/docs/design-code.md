# Servio Design Code

## UX/UI DNA
- Amazon structure
- Farfetch cleanliness
- Wayfair filtering
- Faire clarity
- Airbnb trust clarity

## Product principles
- Search-first UX
- Clean commerce
- High-trust interface
- Clear hierarchy
- Controlled density
- Mobile-first commerce logic
- Progressive disclosure

## Visual code
- крупные белые поверхности
- мягкий светло-серый фон страницы
- primary blue только в точках действия
- спокойные серо-синие нейтрали
- мягкие радиусы
- тонкие границы
- очень лёгкие тени

## Radii
- XS: 8px
- SM: 10px
- MD: 12px
- LG: 16px
- XL: 20px
- Pill: 999px

## What is forbidden
- Visual noise
- Cheap promo style
- Aggressive clutter
- Random radii / shadows / spacing
- Unsystematic components
- Old-Amazon-style overload
- Temu-style retention clutter
